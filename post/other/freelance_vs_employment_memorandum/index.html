1. 契約と法律の枠組み [正社員Win]

一番の違いは「労働者かどうか」。労働者でなくなると労基法の保護が丸ごと外れる。

2. 社会保険 [正社員Win]

「労使折半」が消えるのが体感として最も大きい。同じ保障水準を維持しようとすると負担は概ね倍になる。 退職直後は「国保」と「健保の任意継続（最長2年）」を必ず比較する。前年所得が高いと任意継続のほうが安いことが多い。 ただし任意継続は保険料も労使折半分がなくなり全額自己負担になる。

項目 正社員 個人事業主
医療保険 健康保険（協会けんぽ / 組合健保） 国民健康保険（or 国保組合 / 健保の任意継続）
医療保険料 全国平均 9.9% を労使折半 → 本人 約4.95% 全額自己負担。自治体ごとに所得割＋均等割で算定
年金 厚生年金 ＋ 国民年金（2階建て） 国民年金のみ（1階建て）
年金保険料 18.3% を労使折半 → 本人 9.15% 定額 月 17,920円、全額自己負担
介護保険（40-64歳） 1.62% を労使折半 → 本人 0.81% 全額自己負担（国保に上乗せ）
扶養 あり。配偶者・子を入れても保険料は変わらない なし。国保は世帯人数で保険料が増える
保険料の納付 給与天引き 自分で納付

窓口・サービス 仕組み 概要
みん社保 一般社団法人の理事に就任し、その法人の被保険者になる 月 43,000円の定額で健保 ＋ 厚生年金に加入できるとうたう。所得に連動せず、扶養家族が何人いても定額。業務実態は月15分程度のアンケート回答とされる

Caution

「社保加入サービス」の現在地（2026年3月〜）
この手のスキームは長らく「グレー」と言われてきたが、2026年3月18日に行政が明確に否定する方向へ舵を切った。
厚労省が 法人の役員である個人事業主等に係る被保険者資格の取扱いについて（保保発0318第1号 / 年管管発0318第1号・令和8年3月18日）を協会けんぽ・健保組合・日本年金機構あてに発出した。 通知は冒頭で「社会保険料の削減を謳い、個人事業主やフリーランス等を法人の役員とし、……当該個人事業主等から 会費等と称して役員としての報酬を上回る額を支払わせている 事業所が存在している」と、スキームの構造そのものを名指ししている。

判断軸は2つ。①その業務が経営への参画を内容とする経常的な労務の提供か、②その報酬が業務の対価として経常的に支払われるものか。以下に当たると「健康保険等の適用はない」と判断される。

否定される類型 通知が挙げる該当例
報酬 < 会費 役員報酬を上回る額の会費等を支払っている場合、原則として対価としての経常的な支払いとは認められない。関連法人に会費を払わせる形も同一視される
業務が自己研さんに過ぎない 知識向上のためのアンケートへの回答や勉強会への参加等
単なる活動報告・情報共有 役員としての具体的な指揮監督や権限の行使に当たらないもの
単なる協力・お願い 法人の事業の紹介等にとどまり、労務を提供する義務を負っているとは認められないもの
意見を述べる立場にとどまる 役員会等に出席しているが、役員への連絡調整や職員に対する指揮監督に従事していない場合

総合判断では「指揮命令権を有する職員の有無」「決裁権を有する所管業務の有無」「代表者への報告業務の有無」「定期的な会議への出席頻度とそれ以外の業務・出勤頻度」が見られる。

重いのは否認されたときの帰結のほう。法人に使用されている実態がないと確認された場合、通知は「資格喪失の届出を提出させ、その被保険者資格を喪失させること」と指示している。 さらに、事実と異なる資格取得の届出は 健康保険法48条・厚生年金保険法27条の規定に反する と明記された。喪失すれば本来の国保・国民年金に戻る。

8. 負けっ放しな個人事業主のリベンジ

Tip

補論: 制度に出ない差分

ここまでの表は、並べれば必ず正社員が勝つ。日本の社会保障は被用者を基準に設計されているので、制度の土俵で比べる限り個人事業主は構造的に不利になる。 個人事業主側の旨味は制度の外（単価・裁量・時間の使い方）にあって、表には現れない。「制度で削られる分を、制度の外の何で回収するか」が実際の比較軸になる。

・金銭面

  • 単価の天井が違う … 正社員の年収は等級テーブルと評価制度に縛られる。個人事業主は市場価格に直結する。ただし前述のとおり、社会保険の全額自己負担分と稼働率で割り戻さないと比較にならない
  • 収入源を分散できる … 正社員は収入源が1本で、会社が傾けば100%失う。複数社と契約していれば1社切られても残る。失業給付が無いことの裏返しで、セーフティネットを自分の設計で持つ側に回る
  • 学習投資を税引き前で買える … PC・モニタ・書籍・通信費・家賃按分。投資対象が多い職種ほど 4. の経費計上が効く
  • 退職金を節税しながら自作できる … 小規模企業共済は掛金が全額所得控除で、廃業時の受け取りは 退職所得控除 の対象。入口と出口の両方に効く

・キャリア面

  • 技術スタックとドメインを選べる … 正社員には配属・異動・組織都合のプロジェクト移動がある。案件を選べるとは、スキルの積み方を自分で設計できるということ
  • 経験の密度 … 1〜2年で環境が変わるので、複数のアーキテクチャ・組織文化・失敗パターンを短期間で見る。逆に「1プロダクトを5年育てる」はやりにくい
  • 評価のためのメタ労働が消える … 目標設定・中間面談・360度レビュー・昇格審査・稟議。判断軸が「契約が続くか」だけになる
  • 市場価格で現在地が見える … 社内の評価しか分からない状態が続くと、外に出たときにギャップが露呈する

・時間・場所

  • 指揮命令を受けない（1. の表）ことが、そのまま勤務時間と場所の裁量になる。フルリモート案件なら住所を選べる（海外も可）。フルリモートでなくても、案件ごとに勤務時間・場所を交渉できる。正社員のように「会社の都合で出社・残業・転勤」がない

  • 案件と案件の間を空けられる … 有給の範囲に縛られず、数ヶ月単位で休んで学ぶ・移動する、が制度上できる。当然その間は無収入

  • 辞めるコストが低い … 合わない現場は更新しなければいいだけで、転職回数として記録に残らない

  • nomadORMY … 共立メンテナンス運営の家具付きマンスリー住居。月 108,000円〜、1物件あたり最短1ヶ月〜最長3ヶ月。朝食220円 / 夕食440円（月〜土）。拠点を固定しない働き方向け

    • 参考: 旅がもたらす真の心理効果 ── 「自己の変革」が起こる仕組み（nazology）

  • フルリモート海外案件の情報（X: @fran_actua）

Caution

ここに挙げたものは すべて「案件を継続的に取れる」前提の上に乗っている。単価 × 稼働率が崩れれば、残るのは制度の薄さだけになる。
額面の単価だけで比較すると見誤るのと同じように、制度の表だけで比較しても見誤る。

9. まとめ

・章ごとの勝敗

章 領域 判定 効いている一点 補填・救済
1 契約と法律 正社員 労基法の保護が丸ごと外れる。労働時間の規制も最低賃金も無い 個人事業のミカタ（保険）
2 社会保険 正社員 労使折半の消失。同水準の保障を維持すると負担は概ね倍 みん社保
3 労働保険 正社員 失業給付が無い。労災は任意加入で保険料も自腹 フリーランス労災保険組合
4 税務 個人事業主 実額経費 ＋ 青色65万円 ＋ 赤字の3年繰越
5 休暇・傷病・出産 正社員 「休む＝無収入」がそのまま制度に出る
6 老後・資産形成 draw 公的年金は1階建てだが、自分で積む枠は倍以上ある
7 信用・手続き 正社員 ローン・カード・賃貸の審査。手続きの期限も自己管理
8 制度の外 個人事業主 単価・裁量・時間。ただし稼働が前提

制度の土俵は 5勝2敗1分 で正社員。8. で書いたとおり、日本の社会保障は被用者を基準に設計されているので当然そうなる。 個人事業主が取れるのは 4.（税務）と 8.（制度の外）だけで、勝負はこの2つで 1・2・3・5・7 の失点を回収できるかに絞られる。

・削られるもの / 増えるもの

方向 中身 出典
削られる 労使折半、失業給付、傷病手当金・出産手当金、有給、労災の自動適用、健康診断、退職金、扶養、社会的信用 1・2・3・5・7
増える 実額経費、青色申告特別控除65万円、iDeCo/小規模企業共済/経営セーフティ共済の枠、単価と稼働の交渉余地 4・6・8

削られる側は確定した固定費、増える側は上限があるか、案件が続く前提でしか効かない。この非対称が効く。

・「1.5〜2.0倍」の内訳

額面の単価だけで比較すると必ず見誤る。よく言われる「個人事業主は正社員の 1.5〜2.0 倍稼がないと損」は魔法の数字ではなく、以下の引き算の合計でしかない。先に引いて、後から足すのが正しい順序。

まず引く（正社員なら会社が持っていた分）:

  • 社会保険の事業主負担 … 健保 4.95% ＋ 厚年 9.15% ＝ 約14%、介護保険該当年齢（40-64歳）なら約15%。これに雇用保険・労災の事業主負担が乗る（2.・3.）
  • 稼働できない日 … 有給（5. のとおり年10日〜）＋ 年末年始 ＋ 体調不良。稼働率で 5〜10% 程度は割り戻す必要がある
  • 売上を生まない時間 … 営業・契約交渉・請求・記帳・確定申告（4.）
  • 給付の自前化 … 失業給付と傷病手当金が無い分を、貯蓄か所得補償保険で自分で持つ（3.・5.）
  • 賞与・退職金・各種手当 … 年収に含まれていない分は単価に載せ直す

そのうえで足す（4.・6. で戻る分）:

  • 実額経費（PC・モニタ・書籍・通信費・家賃按分）
  • 青色申告特別控除 最大65万円
  • iDeCo（月6.8万円 → 2027/1〜 7.5万円）・小規模企業共済・経営セーフティ共済の所得控除

・結論

制度で比べる限り個人事業主は構造的に不利で、それは 4. の控除枠では埋まらない。埋めるのは 8.（単価・裁量・時間）であり、その 8. は 「案件を継続的に取れる」という前提の上にしか乗らない。 つまり判断すべきは損得の計算そのものではなく、その前提がどれだけ崩れないか。単価 × 稼働率が崩れたときに残るのは、ここまでの表で並べた制度の薄さだけになる。 後は、いかにしてリスク許容を見極めるか。
