法務

契約形態

  • 委任
  • 請負
    • ⚠️ 偽装請負
      • 契約形式は請負／業務委託なのに、実態は発注者の指揮命令下で労働している状態
      • 多重委託（個人事業主 ← 代理店 ← 顧客企業）の場合、代理店だけが処罰対象ではない。代理店と顧客企業の両方が違法当事者になり得る
偽装請負 ✕ 多重委託の責任構造 
                    (指揮命令？ ← ここが論点)
       ┌───────────────────────────────┐
       ↓                               │
 [個人事業主]                      [顧客企業]   ← 派遣先 / 注文者
       ↑                               ↑
       │ 業務委託契約                  │ 業務委託契約
       │                               │
       └─────────── [代理店] ──────────┘   ← 派遣元 / 元請

  保護される側              処罰対象になり得る両者
当事者 想定される違反 根拠法
代理店（エージェント） 無許可労働者派遣 / 労働者供給事業 / 中間搾取 労働者派遣法、職業安定法44条、労基法6条
顧客企業 違法派遣の役務提供を受ける行為 / 指揮命令の実態主体 労働者派遣法（労働契約申込みみなし制度あり）
個人事業主 原則「保護される側」、処罰対象ではない —
  • 代理店側のリスク: 許可なく派遣的に人を回せば職安法44条違反 → 1年以下の懲役 or 100万円以下の罰金（職安法64条9号）
  • 顧客企業側のリスク: 違法派遣を受け入れていた場合、「労働契約申込みみなし制度」（派遣法40条の6）で 顧客企業がフリーランスに直接労働契約を申し込んだものとみなされる。「代理店から受け取っただけ」では逃げられない
  • フリーランス法との関係: 多重委託の場合、代理店も顧客企業もそれぞれの位置で「特定業務委託事業者」になり得るので、両方に取引条件明示義務／60日支払義務／7禁止行為が課される
実態判定で見られるポイント
  • 指揮命令していたのは誰か（業務指示、勤務時間管理、進捗管理）
  • 報酬の決定権はどこか（代理店がマージンを抜いて支払うだけなら代理店も実質当事者）
  • 代替性・独立性があるか（フリーランスが自分の判断で再委託できなければ請負と言えない）

※ 一般論。具体の疑義は フリーランス・トラブル110番（0120-532-110）か弁護士へ。

フリーランス法

  • 正式名称: 特定受託事業者に係る取引の適正化等に関する法律（通称: フリーランス法 / フリーランス・事業者間取引適正化等法）
  • 施行日: 2024-11-01
  • 目的: フリーランスが安心して働ける環境の整備（取引適正化＋就業環境整備）
  • 所管:
    • 公正取引委員会・中小企業庁 → 取引適正化
    • 厚生労働省 → 就業環境整備
対象者
  • 特定受託事業者（＝フリーランス側）
    • 業務委託を受ける事業者で、従業員を使用しない者
    • 「個人」または「一人社長（他に役員・従業員なし）」
    • 注: 週20h以上かつ31日以上の雇用見込みがある者は「従業員」にカウントされる
  • 特定業務委託事業者（＝発注側）
    • 従業員を雇用する法人または個人事業主
    • 対消費者（BtoC）取引は対象外
発注事業者に課される義務
  • 【全取引】取引条件 9項目 を直ちに書面 or 電磁的方法で明示（口頭NG）
  • 【全取引】報酬支払期日を 60日以内 で設定・支払
  • 【1ヶ月以上の取引】7つの禁止行為を遵守（後述）
  • 【6ヶ月以上の取引】
    • 育児・介護と業務両立への配慮義務
    • 中途解除は原則 30日前予告 + 理由開示
    • ハラスメント対策
禁止される7行為（1ヶ月以上の取引）
  1. 受領拒否
  2. 報酬減額
  3. 返品
  4. 買いたたき
  5. 購入・利用強制
  6. 不当な経済上の利益提供要請
  7. 不当な給付内容変更・やり直し
違反時
  • 行政調査 → 指導・勧告 → 命令 → 企業名公表 → 50万円以下の罰金（命令違反時）
  • 申告を理由とした報復（取引数量削減等）も禁止
実務上の押さえどころ（自分側）
  • 契約前に 9項目の書面明示 を必ず受け取る（口頭発注は要注意）
  • 支払サイトが 60日以内 か確認（エージェント経由でも同じ）
  • 長期案件では中途解除条項（30日前予告／理由開示）を確認
  • 違反を申し出ても発注側は不利益扱い禁止 → 泣き寝入り不要
